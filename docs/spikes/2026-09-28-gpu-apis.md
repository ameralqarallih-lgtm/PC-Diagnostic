# Spike: vendor-neutral GPU telemetry APIs (Phase 3)

Date: 2026-09-28. Machine: Windows 11 (10.0.26200), NVIDIA GeForce RTX 4090 (driver 617.14) plus Intel Graphics (Core Ultra 9 285K).
Method: Microsoft documentation, then a PowerShell `Add-Type` probe against `gdi32.dll`, cross-checked with `nvidia-smi`.

## Results

| Question | Documentation says | Measured | Decision |
|---|---|---|---|
| `IDXGIAdapter3::QueryVideoMemoryInfo` for system VRAM? | "informs the **process** of the current budget and **process usage**" | — | **Not used** for system VRAM. The architecture doc was wrong. Use PDH `\GPU Adapter Memory(*)\Dedicated Usage`. DXGI gives only total dedicated memory. |
| `KMTQAITYPE_ADAPTERPERFDATA` value | Enum listed without numbers (counting the doc list gives 61) | **62** accepted with a 64-byte `D3DKMT_ADAPTER_PERFDATA` | Use 62. |
| `D3DKMT_ADAPTER_PERFDATA` units | Temperature 0.1 °C; Power 0.1 % (percent, **not watts**); memory frequency Hz | 411 → 41.1 °C (nvidia-smi 41 °C); power 76 → 7.6 % (34.75 W / 450 W = 7.7 %); memory 810 MHz (nvidia-smi 810 MHz); fan 0 RPM (fans stopped) | Store power as `power_pct`. Watts come only from vendor APIs (NVML). |
| `KMTQAITYPE_NODEPERFDATA` value and size | Struct shown as 64 bytes (with `Reserved`) | **61** accepted **only with 56 bytes**; 64 is rejected (`STATUS_INVALID_PARAMETER`). Node 0 = 585 MHz, max 3165 MHz (nvidia-smi: 585 / 3165 MHz) | Use 61. Try 64 bytes, then fall back to 56. Node 0 gives the core clock. |
| `KMTQAITYPE_ADAPTERPERFDATA_CAPS` (63) | — | 40 bytes: max fan 3251 RPM, **TemperatureMax 90.0 °C, TemperatureWarning 84.0 °C** | Record in the device inventory; later use as the driver-provided default for GPU temperature triggers. |
| Intel iGPU perf data | — | Calls succeed but every field is 0 | Treat an all-zero perf block as **Unsupported**, never as 0 °C / 0 MHz. |
| Basic Render / render-only adapter | — | All perf queries rejected | Unsupported. |
| `D3DKMT_ADAPTERINFO` (EnumAdapters2) | — | 20 bytes per entry | As documented. |
| NVML location | Ships with the NVIDIA driver | `C:\Windows\System32\nvml.dll`, WHQL-signed | Load by full path only (no DLL search-path planting); absence means NVIDIA details are Unavailable. |

## Consequences for the design

- The GPU core clock is available without vendor SDKs on drivers that implement node perf data. This matters for the "GPU clock suddenly drops" trigger.
- GPU power has two different units: percent of the board limit (D3DKMT, any vendor) and watts (NVML). Both are stored. Neither is converted into the other.
- The hotspot temperature is not exposed by either D3DKMT or public NVML. It remains a Phase 6 sensor-provider item and may stay Unavailable.
